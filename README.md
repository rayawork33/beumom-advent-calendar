# BeUMom Advent Calendar

A gentle, illustrated 24-day Advent calendar for women and moms. Each December day reveals a small gift of care: a letter, permission slip, quiet practice, playful moment, or thoughtful prompt.

## Deploy on Vercel

Import this repository as a new Vercel project. The included `vercel.json` serves the finished static site from `public/`, so no framework selection, build command, output-directory setting, or environment variables are required.

Vercel will automatically publish future commits after the repository is connected.
